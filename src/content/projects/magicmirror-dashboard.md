MagicMirror Dashboard runs a Raspberry Pi behind a two-way mirror to display useful information at a glance. It shows system uptimes, Docker status and a calendar.

The display is driven by a modular Node.js backend, which keeps the individual information modules separate and easy to extend.

The combination of mirror hardware and a Raspberry Pi turns an everyday object into an ambient information surface.
