Luna is an offline voice assistant for Linux and the Raspberry Pi. German speech recognition runs through Vosk and speech output through espeak-ng, so the whole system works without any cloud connection or internet access.

An animated GUI with eyes and colour feedback gives the assistant a visible presence, while it can control music playback and a browser through voice commands.

The assistant is implemented in Python, using pygame for the animated interface and CustomTkinter for the GUI, with a focus on privacy and full local operation.
