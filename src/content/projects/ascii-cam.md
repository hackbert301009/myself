ASCII-Cam converts a live webcam feed into ASCII art in real time and exposes the result as a virtual camera, so it can be streamed directly into Zoom, OBS or Discord.

It offers brightness, contrast and colour controls along with a matrix mode for a different visual style.

The project is built in Python with OpenCV and NumPy for the image processing, PyQt5 for the interface, and PyVirtualCam for the virtual-camera output. This entry is a fork and contribution to the upstream project.
