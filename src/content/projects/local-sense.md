Local Sense is an Android app designed as an everyday companion. At its core is an on-device machine learning model that runs fully offline and adapts to how the user interacts with it.

By keeping inference and data on the device, the app preserves privacy while still personalising over time.

It is built in Kotlin for Android, using Room for local persistence and an on-device ML model for adaptation.
