The AI Email Agent is a modular, AI-powered tool that generates and sends personalized outreach emails. It tailors each message to its recipient, producing drafts that read as individual rather than templated communication.

The agent is multilingual and includes a review step, so generated emails can be checked and adjusted before they are sent rather than dispatched blindly. Multi-provider support means it can run against Groq, Anthropic or OpenAI depending on availability and preference.

Built in Python around an LLM backend, the modular design keeps generation, review and delivery cleanly separated.
