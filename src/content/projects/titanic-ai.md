Spaceship Titanic ML is a machine-learning solution for the Kaggle "Spaceship Titanic" competition. The work centers on extensive feature engineering, deriving more than 40 features from the raw passenger data to expose the signals most useful for prediction.

On the modeling side it uses ensemble learning, combining a Random Forest with Gradient Boosting to improve robustness over any single estimator. This pipeline reaches roughly 80% cross-validation accuracy.

The project is implemented in Python with scikit-learn, serving as a focused end-to-end example of competition-style tabular machine learning.
